🤖 AI Translation Assistant

Speed up translation with AI: Export → Translate → Import

📋 How it works
  1. Fill out English content first
  2. Click "Prepare Translations" to generate fields
  3. Choose your approach:
    • 🌍 All Languages: Export all 6 languages at once for bulk translation
    • Single Language: Export one language at a time
  4. Copy the prompt + JSON and paste to your AI (ChatGPT, Claude, etc.)
  5. IMPORTANT: Copy ONLY the JSON response from AI (no explanations)
  6. Paste the clean JSON back here and click the appropriate import button
⚡ Super Fast: Use "All Languages" to translate all 6 languages in one AI request!
🔧 Clean Format: AI gets clear instructions and returns clean JSON without metadata.
